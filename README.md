# MarketPearls

一个私人收藏夹：把微博、雪球等平台的深度长文，抓取成**单文件、离线、无外链**的阅读页，长期留存、反复读。

## 收藏清单

| 收藏 | 作者 / 平台 | 篇数 | 文件 |
|---|---|---|---|
| 不会游泳的徐胖子 · 微博 | 徐胖子 / 微博 | 23 | `weibo-xu.html` |
| 我如何管理自己的投资 | 阿兰同学 / 雪球 | 5 | `xueqiu-investment.html` |
| 明日的世界 | 阿兰同学 / 雪球 | 7 | `xueqiu-tomorrow.html` |

首页 `index.html` 是一张漂浮星图。点一颗星打开对应归档；在归档内点「← MarketPearls」返回。

## 特性

- 单文件 HTML——图片与头像全部以 base64 内嵌，**零外链**，可离线打开
- 四档底色（暖纸 / 纯白 / 冷灰 / 暗色），通过 `localStorage` 记忆
- 三档字号（标准 / 大 / 特大），特大档与文章标题同字号
- 桌面与手机均适配，无横向溢出

## 如何阅读

- 在线：<https://johnwish1590.github.io/market-pearls/>
- 本地：下载仓库或直接双击 `index.html`——无需网络，无需服务器

## 归档规则

每批内容做完即定稿——**定稿内容之后不再改动**；后续新增以「追加」方式并入。
正文、评论与互动数据均为**各自抓取时刻的快照**（每篇标注镜像时间），不随源平台变动。
