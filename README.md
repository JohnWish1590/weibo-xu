# 网海拾贝

私人收藏夹：把微博、雪球等平台的优质长文抓取下来，做成**单文件、可离线、无外链**的阅读页，长期留存。

首页 `index.html` 是漂浮星图导航，点星进入对应归档，归档页点「← 网海拾贝」返回。

## 特性

- 单文件 HTML，图片 / 头像全部 base64 内嵌，**零外链**，断网也能打开
- 四档底色（暖纸 / 纯白 / 冷灰 / 暗色），`localStorage` 记忆
- 三档字号（标准 / 较大 / 最大），最大档字号等于文章标题
- 桌面 + 手机自适应，横向无溢出

## 存档规则

每一批做完即定稿，**已定稿的内容不再修改**；此后新增内容以「追加」方式并入。
正文、评论与互动数均为**各自抓取时刻的快照**（每篇标注镜像时间），不随原平台现状变化。
