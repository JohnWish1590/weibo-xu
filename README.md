# MarketPearls

A personal collection: long-form posts from Weibo, Xueqiu and similar platforms, captured into **single-file, offline, link-free** reading pages for long-term keeping.

## Collections

| Collection | Author / Platform | Posts | File |
|---|---|---|---|
| Xu · Weibo | Xu / Weibo | 23 | `weibo-xu.html` |

| Tomorrow's World | Alan / Xueqiu | 7 | `xueqiu-tomorrow.html` |

The homepage `index.html` is a floating-star map. Tap a star to open its archive; inside an archive, tap "← MarketPearls" to return.

## Features

- Single-file HTML — images and avatars are all embedded as base64, **zero external links**, opens offline
- Four palettes (warm paper / pure white / cool grey / dark), remembered via `localStorage`
- Three font tiers (standard / larger / largest); the largest tier matches the article title size
- Responsive for desktop and mobile, with no horizontal overflow

## How to read

- Online: <https://johnwish1590.github.io/market-pearls/>
- Local: download the repo or just double-click `index.html` — no network, no server needed

## Archiving rules

Each batch is finalized when done — **finalized content is not changed afterward**; later additions are merged by append.
Post bodies, comments and engagement counts are each **snapshots taken at their own capture time** (each post is tagged with its mirror time) and do not change with the source platform.

## Notes

- Text-only archive; the pages contain no outbound links to the source platforms.
- Copyright of the content belongs to the original authors and commenters. This repo is for personal long-term reading only — not for redistribution or commercial use.
- The repo can be removed at any time upon request from an original author or commenter.
